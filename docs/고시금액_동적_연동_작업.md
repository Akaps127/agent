# 고시금액 동적 연동 및 자동 추출 작업 가이드

본 문서는 프로젝트 내 하드코딩된 '고시금액(2.3억 원)' 기준을 한국법제처 API와 연동하여 동적으로 관리하도록 개선한 작업 내역을 정리합니다.

## 📅 작업 정보
- **작업 일시**: 2025-12-18
- **핵심 목표**: 매년/격년으로 변동될 수 있는 기획재정부 고시금액을 시스템이 자동으로 인식하게 함

## 🏗️ 시스템 아키텍처

1. **Fetcher (`src/utils/notice_fetcher.py`)**: 법제처 API를 통해 최신 문서를 검색하고 텍스트 내에서 금액을 추출
2. **Config (`src/config.py`)**: 추출된 금액을 메모리에 유지하고, 시스템 전역에 제공하는 중앙 설정 관리
3. **Integration (`server.py`)**: 서버 시작 시(Lifespan) Fetcher를 실행하여 Config를 초기화
4. **Usage (`planner.py`, `writer.py`)**: 하드코딩된 상수 대신 Config의 `get_limit_gosi()` 함수 호출

---

## 🛠️ 주요 컴포넌트 상세

### 1. 고시금액 추출 유틸리티 (`src/utils/notice_fetcher.py`)
- **API**: `https://www.law.go.kr/DRF`
- **인증**: OC ID (`leejayy4` 기본값 사용)
- **로직**:
    - `lawSearch.do`: "기획재정부장관이 정하는 고시금액" 쿼리로 행정규칙 검색
    - `lawService.do`: 검색된 문서의 일련번호로 상세 XML 조회
    - `Regex Parsing`: "물품 및 용역" 문구 근처의 "X억 X천만원" 패턴 분석하여 정수화 (예: 230,000,000)

### 2. 중앙 설정 모듈 (`src/config.py`)
- **기능**: 시스템 내부에서 사용되는 `LIMIT_GOSI` 값을 관리
- **Fallback**: API 호출 실패 시 기존 기준인 `230,000,000`을 기본값으로 유지하여 시스템 안정성 확보
- **주요 함수**:
    - `get_limit_gosi()`: 현재 설정된 고시금액 반환
    - `initialize_notice_amount()`: API 연동 및 업데이트 실행

### 3. 서버 연동 (`server.py`)
- **Lifespan Handler**: FastAPI의 `lifespan` 기능을 사용하여 서버가 뜰 때 `initialize_notice_amount()`를 비동기로 실행
- **사용자 경험**: 서버 로그를 통해 "[INFO] Updated LIMIT_GOSI: 230,000,000원" 메시지 확인 가능

## 🔄 코드 수정 사항 내역

### Planner (`src/nodes/planner.py`)
- `LIMIT_GOSI = 230000000` 삭제
- `get_limit_gosi()`를 통해 낙찰 방법(소액수의/적격심사) 및 적격심사 별표 기준 자동 선택

### Writer (`src/nodes/writer.py`)
- 하드코딩된 고시금액 기준 삭제
- `config` 모듈에서 기준값을 가져와 공고문의 기업 제한 내용(라 항목) 동적 생성

## 🧪 테스트 및 검증 방법

### 1. 유틸리티 단독 테스트
```bash
python src/utils/notice_fetcher.py
```
- API 접속 및 금액 추출 여부를 즉시 확인 가능합니다. (Windows 인코딩 대응 완료)

### 2. 서버 연동 테스트
- 서버 실행 시 로그에 고시금액 초기화 성공 메시지가 남는지 확인하십시오.

## 📝 향후 유지보수 참고 사항
- **변동 주기**: 고시금액은 보통 1~2년에 한 번 변동됩니다.
- **정규식**: 법령의 문구 형식이 "2억 5천만원" 등으로 변할 경우 `notice_fetcher.py`의 정규식 패턴 수정이 필요할 수 있습니다.
- **API 키**: `leejayy4` OC ID가 만료되거나 변경될 경우 `.env` 파일의 `LAW_OC_ID` 값을 업데이트하십시오.
